How to take a screen shot

Using a Mac

  1. On your keybord press and hold Cmd and Shift and either 3 or 4 or 5
    • Use 3 if you wish to get a screen shot or your entire screen
    • Use 4 if you wish to only get a portion of your screen
    • Use 5 to get options to get your whole screen or part of your screen or a whole window. Also here you can choose from the same options but instead to record a video from your screen.
    • If you chose to use 3 then you will be complete and should see a preview of it popup in the lower right hand corner of your screen
    • If you chose to use 4 then you will want to click in the starting corner of your screenshot and then drag the mouse while it is still clicked down to the corner opposite of where you started to select the entire area you would like screen shot
    • Using option 5 you now need to select which method of screen shot you would like to use
    • If you chose to use 4 then you will be complete and should see a preview of it popup in the lower right hand corner of your screen
      • If you chose the entire screen click the screen and you should be done.
      • If you chose a part of the screen go back to step two and proceed with if you had used 4.
      • if you chose a window click on the window you wish to screen shot and then you should be done.

On Windows

  1. Navigate to the Windows Start Menu
  2. Search in the search bar for snipping tool
  3. Click on the snipping tool
  4. Select the part of the screen you wish to copy by click in the starting corner of your screenshot and then drag the mouse while it is still clicked down to the corner opposite

How to submit an assigment on canvas

  1. Go to the assignment you wish to submit
  2. Click the button that says "Start Assignment"
    • If you are submiting via a text box you will then type your response in the text box
    • If you are submitting by a file you will then click upload file and the navigate in your files to the file you wish to uplaod
  4. Press "Submit"

How to use common Keyboard Commands

Mac

  • As mentioned in the screen shot section CmdShift3or4or5 can all be used to take screenshots
  • CmdC will copy both text and files
  • CmdX will cut both text and files meaning it will be removed from the current location and coppied
  • CmdV will paste both text and files that have been either copied or cut
  • CmdA will select everything
  • CmdSpace (quick press) will bring up Spotlight search
  • CmdSpace (hold) will bring up Siri

Windows

  • CtlC will copy both text and files
  • CtlX will cut both text and files meaning it will be removed from the current location and coppied
  • CtlV will paste both text and files that have been either copied or cut
  • CtlA will select everything
  • CtlAltDelete will bring up a screen to lock or switch user or sign out or change password or open task manager
